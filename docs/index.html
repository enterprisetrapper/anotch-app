Team call
What is the difference between optimistic and pessimistic locking?
Answer
Optimistic checks at save time. Pessimistic locks first.
Optimistic checks a version number when you save and rejects stale writes. Pessimistic takes the lock up front, so others wait.
Use optimistic locking when conflicts are rare. Lock first when retries are costly.

02Answers

One line first. Detail only if you want it.

Answer
Optimistic checks at save time. Pessimistic locks first.
Optimistic locking lets everyone read and write freely, then checks a version number at save time and rejects the write if the row changed. Pessimistic locking takes a lock up front, so others wait until you finish.
Use optimistic when conflicts are rare. Use pessimistic when they are common or costly to retry.
